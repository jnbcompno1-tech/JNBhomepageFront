## 새 세션 시작 방법

1. 이 문서, 저장소 지침, 현재 `git status`와 최근 커밋을 읽는다. 기준 커밋 이후 변경도 확인한다.
2. 아래 작업표에서 미배정 **묶음**을 선택하고 담당 세션·시작 시각·상태를 기록한다. 같은 묶음을 다른 세션이 진행 중이면 중복 작업하지 않는다.
3. 선행 조건과 파일 담당 범위를 확인한다. 공통 파일을 수정해야 하면 담당 세션과 순서를 정한다. 가능하면 별도 브랜치/작업 공간을 사용한다.
4. 작업별 완료 기준을 충족하고 검증한 뒤 Conventional Commits 형식으로 커밋한다. 사용자가 요청한 작업별 커밋·푸시 원칙을 따른다. 푸시 전 원격 변경을 확인하고 강제 푸시는 하지 않는다.
5. 체크박스·작업표·완료 기록을 함께 갱신한다. 확인하지 못한 외부 조건은 완료로 표시하지 않는다. 이 문서는 충돌이 잦은 공통 파일이므로 자기 묶음의 항목과 완료 기록만 수정하고, 푸시 직전에 원격 최신본을 받아 병합한다.

다른 세션에 전달할 요청 예시:

> `docs/production-release-checklist.md`를 읽고 묶음 A를 맡아 진행해줘. 담당과 상태를 기록하고, 다른 묶음의 파일을 건드리지 않도록 범위를 지켜줘. 완료 기준에 따라 검증한 뒤 작업별 커밋·푸시와 완료 기록까지 남겨줘.

- [ ] 공개·검토용 설정 테스트를 실행하고 결과를 기록한다.
